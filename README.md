# KWin Shortcut Overlay

A lightweight, high-performance desktop cheatsheet overlay for KDE Plasma 6. Built with Rust and Slint, it parses your local shortcut configurations and displays them in a clean, searchable, and modern interface.

## Features

* **Instant Access:** Pops up instantly with a global shortcut (`Meta` + `/`).
* **Fuzzy Search:** Filter through all your registered shortcuts instantly.
* **Single Instance Toggle:** Pressing the shortcut again cleanly toggles (hides) the window.
* **Wayland Ready**

## Installation

```bash
curl -sSfL [https://raw.githubusercontent.com/OJUrbaniak/kwin-shortcut-overlay/main/install.sh](https://raw.githubusercontent.com/OJUrbaniak/kwin-shortcut-overlay/main/install.sh) | bash
```
